# ЛР7, Обобщения и лямбда-выражения
Реализация бинарного дерева поиска на языке C#.

Бинарное дерево поиска — структура данных для работы с упорядоченными множествами. Если x — узел бинарного дерева с ключом k, то все узлы в левом поддереве должны иметь ключи, которые меньше k, а в правом поддереве — больше k.
